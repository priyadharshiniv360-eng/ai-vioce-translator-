# 🌍 AI Language Translator using NLP

## 📖 Project Overview
The AI Language Translator is a web-based application that translates text and speech between multiple languages using Natural Language Processing (NLP).

## 🚀 Features
- Text-to-Text Translation
- Speech-to-Text Translation
- Text-to-Speech Translation
- Speech-to-Speech Translation
- Gamified Language Learning
- Animated Panda Assistant
- Language Flags
- Responsive UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Python
- NLP
- Speech Recognition
- gTTS

## ⚙️ Installation
1. Clone the repository.
2. Create a virtual environment.
3. Install requirements.
4. Run the application.
